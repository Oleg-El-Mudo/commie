

# Комми

**Комми** — это мобильный мессенджер, работающий в одноранговой сети с поддержкой сквозного шифрования. Приложение разработано для операционной системы **Аврора**, начиная с версии 5.

## Описание

Комми — децентрализованный мессенджер, в котором все данные хранятся локально на устройстве пользователя. Отсутствует центральный сервер, а обмен сообщениями осуществляется напрямую между пользователями по защищённому каналу. Ключевые особенности:
- Работа в одноранговой (P2P) сети
- Сквозное шифрование (шифрование на стороне отправителя)
- Поддержка личных и секретных чатов
- Локальное хранение данных
- Генерация и использование пригласительных ссылок для добавления контактов

## Требования

- **ОС**: Аврора, версия 5 и выше
- **Среда разработки**: Aurora IDE

## Варианты использования

### 1. Регистрация
Пользователь регистрируется локально на своём устройстве. Уникальность аккаунта обеспечивается только в рамках одного устройства, так как система децентрализована. Для регистрации необходимо:
- Указать логин
- Ввести пароль, соответствующий следующим требованиям:
  - Минимум 15 символов
  - Наличие заглавных и строчных букв
  - Наличие цифр и специальных символов
- Пароль хэшируется и сохраняется в базе данных.
На одном устройстве можно зарегистрировать несколько пользователей, но активным может быть только один.

### 2. Авторизация
Для входа в систему необходимо:
- Ввести логин
- Ввести пароль
Пароль хэшируется и сравнивается с сохранённым значением в БД. Авторизация возможна только в уже зарегистрированные аккаунты, находящиеся на этом устройстве.

### 3. Работа с контактами
Для связи между узлами используется система **пригласительных ссылок**. Ссылка содержит зашифрованную информацию: логин, псевдоним (если есть), IP-адрес, порт, публичные ключи.

#### Генерация ссылки:
1. Перейти на страницу "Приглашения"
2. Нажать кнопку генерации ссылки
3. Скопировать ссылку или открыть её в виде QR-кода

#### Добавление контакта:
1. Ввести пригласительную ссылку вручную → нажать "Добавить контакт"
2. Или отсканировать QR-код → нажать "Добавить контакт"

> При изменении контактных данных требуется повторно сгенерировать ссылку. Старый контакт будет заменён на новый.

### 4. Чат «Избранное»
«Избранное» — локальный чат, не требующий соединения с другими узлами. Сообщения сохраняются в локальной базе данных и доступны только текущему пользователю. Поддерживает текстовый формат сообщений.

### 5. Личные чаты
Общение происходит между пользователем и его контактом. Контакт должен быть онлайн.

При отправке:
- Сообщение шифруется публичным ключом собеседника
- Сохраняется в БД в зашифрованном виде

При получении:
- Сообщение расшифровывается приватным ключом

### 6. Секретные чаты
Секретные чаты аналогичны личным, однако сообщения **не сохраняются** в базе данных. После перезагрузки страницы или выхода из чата информация удаляется.

### 7. Псевдоним пользователя
Псевдоним отображается вместо логина в списке контактов и в чатах.

Чтобы изменить/добавить:
1. Перейти в настройки
2. Ввести желаемое имя
3. Нажать кнопку сохранения

### 8. Смена пароля
Пользователь может изменить пароль, если он соответствует всем требованиям безопасности:
- Минимум 15 символов
- Разный регистр
- Цифры и спецсимволы

Новый пароль проверяется системой и сохраняется в хэшированном виде.

### 9. Информация о проекте
В настройках предусмотрена возможность просмотра информации о проекте, авторе и перехода к репозиторию с исходным кодом.

### 10. Удаление всех данных
Пользователь может удалить все данные, включая:
- Зарегистрированных пользователей
- Контакты
- Сообщения

 **Восстановление после удаления невозможно!**
